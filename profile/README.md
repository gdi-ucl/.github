# Global Disability Innovation Hub

GDI Hub brings research and practice together to advance disability innovation. Based at UCL, its work connects assistive technology, inclusive design and education with global partnerships. Its Academic Research Centre and Community Interest Company contribute complementary research and delivery expertise.

[Visit GDI’s website](https://www.disabilityinnovation.com) · [Explore the Hub](https://github.com/gdi-ucl/gdi-hub) · [Publications](https://github.com/gdi-ucl/gdi-hub/blob/main/PUBLICATIONS.md)

## For researchers

Create one repository per project. Use your individual GitHub account to collaborate in this shared organisation. Project leads choose public or private visibility and manage their project’s access; only publish material you are authorised to share. Private projects are visible only to their authorised collaborators.

New to the organisation? Ask the GDI workspace maintainer for membership. Public templates can be read by anyone; creating a project under `gdi-ucl` requires membership and creation permission.

## About this GitHub workspace

The repositories hold project introductions, software and supporting instructions. Research datasets and participant material stay in approved project storage. The [GDI website](https://www.disabilityinnovation.com) remains the source for institutional information and publications.
